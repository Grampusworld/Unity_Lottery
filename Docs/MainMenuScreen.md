# LOTTERY MANIA 主菜单

## 使用

打开 `Assets/Scenes/SampleScene.unity` 并按 Play，会先显示像素风主菜单。

- **NEW GAME**：已有存档时先弹出覆盖确认，默认选中 CANCEL。确认后重置当前 v3 游戏进度并重新加载游戏；没有存档时直接开始。
- **CONTINUE**：继续余额、解锁、升级和刮票计数；没有存档时置灰。
- **SETTING**：减少动态效果、全屏／窗口模式。点击切换后自动保存，BACK 返回来源界面。
- **Esc**：游戏中打开暂停菜单；暂停界面再次按 Esc 恢复；设置或确认框中按 Esc 返回／取消。
- 暂停菜单提供 **RESUME / SETTING / MAIN MENU**。菜单打开时机器停止计时，商店、刮奖和桌面拖拽不能操作；菜单按钮仍可播放果冻反馈。
- 方向键选择按钮，Enter 提交当前按钮。

## 存档与生命周期

主菜单采用当前场景内的独立 uGUI 浮层，因此一次运行中返回主菜单再 CONTINUE，不会丢失桌面未完成的彩票、盘子或机器周期。

磁盘存档沿用 `LotteryPrototype.v3.*`。新增 `HasStarted` 标记防止第一次只打开菜单便被误认为已开始游戏；已有 v3 `Balance` 键仍可识别为有效存档。仅进入游戏后才允许写游戏进度，确认 NEW GAME 会先关闭旧实例写档权限，再删除当前游戏的已知键并重新加载场景。调试重置沿用同一组键。

**关闭程序后恢复的内容沿用原有存档范围**：余额、解锁、升级、刮票计数。未完成的彩票、桌面盘子、机器队列及周期未新增磁盘存储。

设置独立保存：

- 减少动态效果：沿用 `LotteryPrototype.v1.ReduceMotion`，实时通知现有动效组件。
- 显示模式：`LotteryMania.Settings.FullScreen`，独立构建中切换 `FullScreenWindow / Windowed`。Unity Editor 的 Game 视图不会切换操作系统窗口；实际窗口切换须在独立运行的游戏中检查。
- NEW GAME 和调试重置不会删除设置。

## 编辑与配置

- 场景 `MainMenuCanvas` 内四个可编辑面板：`MainPanel / PausePanel / SettingsPanel / NewGameConfirmation`。
- `MainMenuScreen` 管理视图、暂停、焦点、设置和存档入口；`LotteryGame` 继续负责游戏进度。
- 主菜单画布参考尺寸 1280×720，排序为 100；游戏 HUD 不改布局。
- 使用现有 Press Start 2P、Table、彩票、海绵和机器素材；无新增字体、音频或包。
- `Tools/Lottery/Add Main Menu Screen` 为首次装配工具；已存在菜单时会拒绝重复添加，避免覆盖手动编辑。
- Build Settings 仍使用原有 SampleScene，不需要新场景。
