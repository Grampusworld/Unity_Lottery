检查来源：`/Users/maolinlu/Unity Projects/Materials/kenney_interface-sounds/Audio`。完整检查结果及最终导入选择；下方六个新增音效已接入项目。

## 方法和限制

- 完整读取所有文件的 Ogg Vorbis 元数据；用本机 VideoFusion 附带的 ffmpeg 完整解码为 PCM，再测量有效样本、峰值、RMS 和哈希。
- 以下时长优先采用 Ogg granule position 的容器时长。部分极短 Vorbis 文件的解码 PCM 时长与容器时长相差约 10–23 ms；独立记录在 JSON/CSV 中，不能据此判定损坏。
- 没有实际试听。候选适配依据为文件类别名称、时长、声道和声级数据；音色、悦耳程度、是否符合美术风格仍需试听决定。

## 总体结果

- 100 个文件，20 类，全部 `.ogg` / Vorbis，总大小 960,599 字节（约 938 KiB）。
- 全部 44,100 Hz；77 个单声道、23 个双声道。
- 100/100 完整解码成功，零解码警告；没有空文件、全静音素材或整数 PCM 削顶样本。
- 原文件 SHA-256、解码 PCM SHA-256、转单声道 PCM SHA-256 均没有完全重复。
- 全包时长范围约 0.010–1.944 秒；峰值为 -1.36 至接近 0 dBFS，播放时应使用既有统一音效音量，避免原始峰值过响。
