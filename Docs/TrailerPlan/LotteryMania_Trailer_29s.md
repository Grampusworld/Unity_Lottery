# LOTTERY MANIA · 29 秒宣传视频方案

核对日期：2026-10-05。依据当前工作区（HEAD `cafa39b`）的代码、资源、SampleScene 场景文件及 Unity 中实际挂接的组件与 UI 文本。

## 已确认的游戏内容

- **名称**：游戏内标题为 `LOTTERY MANIA`，README 使用「挂个爽 · Lottery Mania」。宣传片保留游戏原有英文标题。Unity 产品设置中的 `My project (2D)` 是项目名，不用作宣传片名。
- **类型与调性**：鼠标操作的 2D 像素风增量游戏。橙棕桌面、深蓝金框界面、米白文字与青绿色强调色；动作有果冻弹性、飞入、缩小退场和短促音效。整体适合轻松、俏皮、带一点荒诞的节奏。
- **核心循环**：洗盘子赚本金 → 购买与刮开彩票 → 获得收益、解锁票种 → 升级设备与收益倍率 → 向持有 $2,000,000 现金的目标推进。
- **彩票**：LUCKY、GOLD、NOVA、HEARTMATCH、CROSSCODE、ZIGZAG。前三种揭晓奖金，后三种分别有同号组合、中心匹配和递增数字规则。彩票有赚有赔。
- **特色系统**：黄／紫海绵、盘子价值与数量升级、自动洗盘机、自动刮票机及其速度／容量升级、购票后自动投喂、各票种 10／25／50 张的全局收益倍率里程碑。
- **场景与关卡**：当前只有一个启用的游戏场景 `SampleScene`，主要空间是同一张桌面；成长来自票种、设备和数值升级，没有独立地图关卡。片中通过桌面不同区域与界面切换形成镜头变化。
- **角色**：已实现五页新手引导中的猫老板，两张猫咪表情图。设定是公元 9999 年，为猫购买 $2,000,000 的昂贵猫粮。猫咪是引导角色。
- **UI**：左侧 `TICKETS / GADGETS` 商店、余额、票种进度、设备等级与价格、机器队列／进度环、顶部目标进度与倍率、五页教程、暂停／设置、通关统计面板。
- **主菜单**：中央深蓝金框面板；两行标题 `LOTTERY / MANIA`；副标 `SCRATCH. SCRUB. GROW.`；三个按钮 `NEW GAME / CONTINUE / SETTING`；周围点缀彩票、洗盘机、CRT 刮票机与海绵。

## 创意与规格

**主题：猫老板的两百万猫粮计划。**

用一次真实中奖的瞬间吸引注意，再让观众看懂「洗盘起步—刮票与升级—机器接班—猫粮目标」的成长过程。29 秒，16:9，建议 2560×1440 原生录制，60 fps。轻快的实录剪辑，无旁白，少量中文短字幕；原游戏英文 UI 保留。

全部游戏画面取自当前项目录屏。推近、横移、匹配剪辑属于后期镜头处理；保留游戏本身的像素烟花、金币、弹性和机器动画。像素边缘保持清晰，运镜幅度克制。

## 录制清单与真实性约束

1. 一次实际中奖的手动刮票，连同烟花、金币与余额栏录下。手动中奖烟花不能移植到机器结算，也不表现为每张票必赚。
2. 教程第一页猫咪、黄海绵擦盘、紫海绵清洁，各保留动作前后余量。
3. 六种票面的独立录屏；运行时文本覆盖后的数字才用于成片，不用 Prefab 的编辑态占位金额。
4. 商店切页、一次成功升级、彩票手动入机、洗盘机与刮票机运行及完成。
5. 一次真实里程碑达成，以及目标／倍率 HUD。自动刮票机是串行队列；自动投喂需要玩家购票，不描绘成全自动购票或所有槽位并行处理。
6. 完整主菜单录屏至少六秒，包含悬停前后余量；成片使用最后四秒。保留原画面名称和按钮，不添加尚未提供的发行日期、平台或商店徽标。
