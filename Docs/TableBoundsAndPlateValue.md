# 桌面边界、洗盘机显示与盘子价值

## 使用

运行 `Assets/Scenes/SampleScene.unity`。GADGETS 第一行是 **PLATE VALUE**，显示当前与下一级每盘收益、当前等级及购买费用。初始价值为 $1，升级同时作用于手洗和自动洗盘机。

| 升级后等级 | 每盘收益 | 本次升级费用 |
| --- | ---: | ---: |
| 0 | $1 | — |
| 1 | $3 | $20 |
| 2 | $5 | $50 |
| 3 | $10 | $200 |
| 4 | $20 | $500 |
| 5 | $30 | $1,000 |

洗盘机每轮收益 = 当轮容量 × 结算时的盘子价值。例如初始 5 盘、价值升到 $3 后，每轮获得 $15；满容量 40 盘、价值升到 $30 后，每轮获得 $1,200。升级不重新开始正在进行的清洗周期。手洗盘子尺寸与堆叠规则不变，完成时按当前价值结算，沿用原有金币动画。

满级后按钮转为既有金色状态牌并停止果冻反馈，不再扣钱。余额不足则触发已有的余额反馈。`LotteryPrototype.v1.PlateValueLevel` 自动保存等级，旧存档缺少此项时从 0 级开始；F1 菜单的重置进度会同时清除该等级。

## 移动边界

- 海绵与两台机器完整留在橙色桌面的黑色内框之间，并扣除左侧商店的遮挡区域。
- 桌面像素矩形为 `(63, 133, 89, 47)`，由海绵和机器共享。相机和商店尺寸变化时重新换算。
- 边界预留果冻的 1.5 倍最大尺寸，同时包括机器进度环和刮票机下方的计数牌。
- 拖动、松手惯性、碰撞推离与重置设计位置均使用同一边界；碰撞推离被桌沿挡住时尝试其他方向。
- 机器初始设计位若无法容纳完整外观，会自动移入安全位置。入场动画仍沿用原来的表现。

## 洗盘机内窗

盘子槽位与水流共用真实玻璃窗的几何配置（90×34 机身像素）。布局在窗内再留一圈像素，随机器果冻缩放重新排列；保留真实容量对应的盘子数量和均匀缩放。叠层间距可缩至 0，容量增加不会把盘子高塔撑出窗。

运行时创建窗口 SpriteMask，前后绘制顺序严格包住盘子层。盘子飞入接触机身时开始受遮罩约束，到位及缩小退场也受约束。水流、气泡、盘子飞入与原有果冻脉冲保留，不改美术 PNG。

## 彩票概率

六个预制体继续保留原来的 `prizes` 奖池字段。抽奖先以原空奖率减 10 个百分点判定是否空奖，再从正奖金条目中等概率抽取，因此正奖金重复项的相对权重不变。

| 彩票 | 原空奖率 | 当前空奖率 |
| --- | ---: | ---: |
| Lucky | 20% | 10% |
| Gold | 25% | 15% |
| Nova | 25% | 15% |
| HeartMatch | 42.857% | 32.857% |
| CrossCode | 28.571% | 18.571% |
| ZigzagRun | 42.857% | 32.857% |

奖金数额、票价、解锁费、里程碑与多数字中奖规则保持原配置。奖池为空或没有正奖金时安全返回 0。`LotteryEconomy.EmptyPrizeReduction`、`PlateValues` 和 `PlateValueCosts` 是调整入口。

## 编辑器维护

`Tools > Lottery > Apply Table Bounds And Plate Value` 可重新装配首行按钮、引用和桌面边界，重复执行复用同一按钮，不重复绑定点击事件。原有 ScratcherSetup 和 MachineDragSetup 同步支持新增行及安全边界。

此前 30–60 分钟成长模拟属于旧经济版本，不包含本次盘子价值升级和空奖率调整。新的升级成本按用户指定配置，尤其高级洗盘机收益会明显提高；不将旧模拟时长视为当前版本实测时长。

## 验证记录

- Unity Editor 编译无错误，场景引用与点击事件有效。
- 六种彩票各抽取 100,000 次，共 600,000 次；空奖率与配置目标一致，正奖金相对权重保留。三种多数字票各检查 1,000 组，数字规则与抽定奖金一致。
- 三种刮票机外观、洗盘机、两种海绵共执行 1,200 次随机极端位置与碰撞边界检查。
- 注入实际鼠标输入，验证三个物件抓取、四角屏幕外拖动、松手，以及惯性停止前的逐帧边界。
- 洗盘机六档容量（5/8/12/18/27/40）在 0.5/1/1.5 倍机身缩放下，每个盘子都完整位于真实内窗，保持等比例。运行截图确认盘子、水流与气泡可见，外壳没有被盘子覆盖。
- 六档盘子价值均通过真实擦除污渍结算与洗盘机一轮 Update 结算；五次按钮扣费、重复擦洗不重复结算、满级限制、资金不足反馈、保存重载、调试重置及异常存档等级检查通过。
- 收益测试操作内包含完整存档备份与恢复；任务结束再次核对恢复任务开始时的全部 22 项键值与缺失状态。测试临时数据未写入最终场景。
