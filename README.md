# Unity Lottery（挂个爽）

一款使用 Unity 6 和 C# 制作的 2D 像素风刮刮乐 + 放置小游戏。点击按钮领取彩票，用鼠标刮开涂层领取随机奖金；也可以手动刷盘子，或解锁自动洗碗机与自动刮彩票机，让余额自己涨。

> **项目状态：** 当前提供 Unity 工程，可在编辑器中试玩。仓库暂未提供可直接双击运行的游戏安装包或可执行文件。

## 玩法

### 刮彩票

1. 在左侧商店的 **TICKETS** 页点击票种按钮，花钱生成一张彩票。彩票会从屏幕右边界外飞入桌面，飞行途中带速度形变，**落地之前刮不动**。
2. 按住鼠标左键，在涂层上拖动刮开。刮开面积达到 80% 后自动揭晓奖金，更新右上角 **MONEY** 余额。
3. 彩票停留约 2 秒后消失，按钮恢复可用。

| 票种 | 售价 | 奖池（等概率） |
| --- | --- | --- |
| LUCKY | $10 | 0 / 5 / 10 / 20 / 50 |
| GOLD | $50（首次 $100 解锁） | 100 / 200 / 500 |
| NOVA | $50（首次 $1000 解锁） | 500 / 1000 / 2000 |

每种票累计刮满 10 / 25 / 50 张时，还会额外发放里程碑奖金。

### 自动刮彩票机

把彩票丢进去，机器自己刮、自己结算。

1. 在 **GADGETS** 页花 **$300** 解锁，机器会从上方落到桌面。
2. **按住左键 0.2 秒**把桌上的彩票拿起来（见下方「操作」），拖到机器上松手即投入。
3. 每张票在机内独立计时，到时自动按**这张票自己抽中的奖金**结算。

| 升级项 | 效果 | 价格 |
| --- | --- | --- |
| SCRATCHER SPEED | 每级 −1 秒（8s → 3s），最高 5 级 | 每级 $1 |
| SCRATCHER CAPACITY | 每级 +1 张同时处理（1 → 6 张），最高 5 级 | 每级 $1 |

机身外观由**速度等级 + 容量等级**的总和决定，一共三档：

| 总等级 | 外观 |
| --- | --- |
| 0–3 | Retro CRT |
| 4–6 | Classic Blue |
| 7–10 | Gold Deluxe |

进度环只显示机内**最靠前**那张票的进度。

### 洗碗

- 点击 **One More Plate** 生成一个脏盘子，拖动海绵刷干净即可获得收入。
- **PURPLE SPONGE**（$30）：刷头半径翻倍。
- **UNLOCK WASHER**（$200）：解锁自动洗碗机，每 10 秒自动产出 $5；可继续升级速度（最高 5 级）与容量（最高 5 级）。

余额、解锁状态与升级等级保存在 `PlayerPrefs` 中，重开游戏会保留。

## 操作

| 按键 / 操作 | 作用 |
| --- | --- |
| 鼠标左键拖动 | 刮彩票、拖动海绵 |
| 鼠标左键按住 0.2 秒 | 拿起桌面彩票拖拽；松手时不在机器上则飞回原位 |
| `F1` | 显示 / 隐藏 Debug 面板 |
| Debug 面板 `Reduce Motion` | 切换降低动效档（悬停果冻降到 80ms、无回弹、幅度减半） |

> 拿取与刮奖靠**是否移动**区分：按住后立刻拖动 = 刮奖，按住不动满 0.2 秒 = 拿起。

## 在 Unity 中试玩

1. 克隆仓库：

   ```bash
   git clone https://github.com/Grampusworld/Unity_Lottery.git
   ```

2. 在 **Unity Hub → Add project from disk** 中选择克隆得到的 `Unity_Lottery` 文件夹。
3. 使用 **Unity 6.5（6000.5.5f1）** 打开项目。首次打开时，Unity 需要导入素材和软件包，可能要等待一段时间。
4. 打开 `Assets/Scenes/SampleScene.unity`，点击编辑器上方的 **Play**。
5. 在 **Game** 窗口点击票种按钮，等彩票落到桌面后按住鼠标左键刮开。

场景与素材已经全部保存在仓库里，正常情况不需要额外操作。如果需要重建某个子系统，编辑器菜单 **Tools/挂个爽/** 下提供了幂等的一键装配工具，可重复执行：

| 菜单项 | 作用 |
| --- | --- |
| 一键挂载悬停果冻 | 给场景里新增的交互元素补 `HoverJelly` |
| 一键装配洗盘机入场与进度环 | 重建洗碗机的盘子入场、水体与进度环 |
| 一键装配自动刮彩票机 | 导入机器素材、建物体树、铺 7 行 Gadgets 按钮、给票 Prefab 挂入场动画与拖拽 |
| 给票按钮加图标 | 按当前文案宽度重算三个出票按钮的图标位置 |

## 实现要点

- **刮涂层**：运行时复制涂层贴图并擦除像素，不修改原始 PNG；按已擦除像素比例判定完成，同一张彩票不会重复结算。
- **奖池数据化**：奖池配置在各票种预制体的 `LotteryTicket.prizes` 上，新增票种只需加预制体 + 按钮 + 回填引用，不需要改脚本逻辑。
- **彩票入场动画**：`TicketFlyIn` 在初始化时把票挪到屏幕右边界外，再按 `easeOutCubic` 加抛物线弧度飞回桌位；形变由**当前速度**换算（越快拉得越长），落地再弹一下。全程关闭涂层输入与拖拽，只在落地回弹的最后一帧交还操作。
- **手势分流**：`TicketDragger` 用「按住静止 0.22 秒」区分拿取与刮奖 —— 位移超过容差即判定为刮奖并把输入交还给 `ScratchCard`，超时仍未移动才拿起（关闭涂层输入、抬升渲染层级、稍微放大）。投料失败会自动飞回原位。
- **自动刮彩票机**：`AutoScratcher` 给每张票一段独立状态机（入槽 → 转运计时 → 出槽），互不阻塞；槽位按机身贴图的**可见内容包围盒**现算并自动收敛列距/层距，票放在独立容器里（`localScale = 1`），不继承机身缩放。结算走 `LotteryGame.AwardMachineTicket`，与手动刮开共用同一套奖金与里程碑逻辑。
- **运行时像素特效**：`ScratcherEffect` 和洗碗机的水体一样直接在运行时生成 `Texture2D`（横向刮擦头 + 落纸屑 + 每张票结算时一圈放射爆点），不引入粒子系统，也不需要额外美术资源；只在整数 texel 变化时重绘。
- **进度环**：世界空间 Canvas + `Image`（Filled / Radial360）。直径按当前档位机身的**可见内容高度**决定，换档时重新居中 —— 直接用 `sprite.bounds` 会把透明留白也算进去，环会飘到机身外面。
- **像素字体**：使用 Press Start 2P，字体图集按 8px 采样点、`Padding = 5` 烘焙；`PixelPerfectCanvasScaler` 把画布缩放吸附为整数，字号取 8 的倍数，保证字形不发糊、笔画粗细一致。
- **悬停果冻反馈**：`HoverJelly` 组件用弹簧-阻尼积分驱动缩放（默认 22px 持续位移 / 30px 峰值，220ms 进入、160ms 移出），子级文字做反向缩放保持清晰，禁用状态与 reduced-motion 自动降级。
- **2D 界面**：全部 UI 使用拉伸锚点 + 对称内缩，配合像素风彩票、桌面素材与字体。

## 项目目录

```text
Assets/
  Editor/         编辑器批量装配工具（Tools/挂个爽/）
  Fonts/          像素字体资源
  Lotteries/      彩票底图、涂层和桌面素材
  Materials/      桌面、洗碗机、自动刮彩票机等素材
  Prefabs/        彩票、脏盘子等预制体
  Scenes/         游戏场景
  Scripts/        刮奖、彩票、洗碗、自动刮票机、结算与动效逻辑
  Settings/       渲染与输入设置
Packages/         Unity 软件包清单
ProjectSettings/  Unity 项目设置
```

主要脚本：

| 脚本 | 职责 |
| --- | --- |
| `LotteryGame.cs` | 余额、解锁、里程碑、机器结算入口、UI 刷新与存档 |
| `LotteryTicket.cs` | 单张彩票的奖池与开奖 |
| `ScratchCard.cs` | 涂层擦除与完成判定 |
| `TicketFlyIn.cs` / `TicketDragger.cs` | 彩票入场动画、按住拿起与拖拽投料 |
| `AutoScratcher.cs` / `ScratcherEffect.cs` | 自动刮彩票机的等级、槽位、进度环与运行时特效 |
| `SpongeDrag.cs` / `DirtyPlate.cs` / `AutomaticDishWasher.cs` | 洗碗玩法 |
| `WasherPlateFeeder.cs` / `WasherWaterEffect.cs` / `WasherProgressRing.cs` | 洗碗机的盘子入场、水体与进度环 |
| `HoverJelly.cs` / `HoverJellySettings.cs` / `HoverJellyDebugToggle.cs` | 悬停果冻反馈 |
| `PixelPerfectCanvasScaler.cs` / `TicketButtonIconLayout.cs` | 整数倍画布缩放、票按钮图标布局 |

项目使用的字体包含 **Press Start 2P**。复用或重新发布素材时，请分别核对相关素材的许可条款。
