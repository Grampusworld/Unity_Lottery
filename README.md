# 挂个爽 · Lottery Mania

**公元 9999 年，你的猫想吃一袋猫粮。价格：$2,000,000。**

<img src="Assets/Materials/Kitty1.png" alt="等待你赚猫粮钱的猫老板" width="144">

“为什么猫粮这么贵？”

“通货膨胀。喵。”

欢迎来到 **Lottery Mania**：一款把洗盘子、刮彩票和机器升级揉在一起的 **2D 像素风增量游戏**。你从一块海绵开始，把洗盘子的零钱换成彩票，再把赚来的钱投入设备。桌上越来越忙，数字越跳越快，而猫老板只关心晚饭什么时候到。

**目标很明确：让手头现金达到 $2,000,000，完成猫粮订单。**

> 当前仓库提供 Unity 项目源码，按下文步骤即可在编辑器里试玩。游戏界面与新手引导为英文。

## 从洗碗工，到猫粮赞助商

### 第一桶金，真的要用海绵擦

点击左下角 **ONE MORE PLATE**，把脏盘子叫上桌。拖动海绵擦掉污渍，赚下第一笔收入。手头紧的时候，盘子永远是可靠的老朋友。

随后可以升级盘子价值、增加同时处理的盘子数量，或换上清洁效率更高的紫色海绵。猫老板没有给你发工资，但至少批准了设备采购。

### 下一张，会不会就中了？

到左侧 **TICKETS** 商店买一张票，按住鼠标刮开涂层，看数字一点点露出来。中奖时有金币与像素烟花，没赚到钱时……海绵还在原来的位置等你。

六种彩票逐步解锁：**LUCKY、GOLD、NOVA、HEARTMATCH、CROSSCODE、ZIGZAG**。除了不同的价格与奖池，还有数字组合、中心匹配、升序等票面规则。彩票有赚有赔，单张中奖不保证收回成本，记得给下一轮留点本钱。

每种彩票累计刮满 **10 / 25 / 50 张**，还能获得里程碑带来的**全局收益倍率提升**。喜欢的低阶票，也有继续刮下去的理由。

### 让机器接班，给双手放个假

在 **GADGETS** 商店逐步搭建你的桌面流水线：

| 设备或升级 | 能帮你做什么 |
| --- | --- |
| 自动洗盘机 | 批量处理盘子，升级速度与容量 |
| 自动刮票机 | 把彩票放进去，排队刮开并结算 |
| 自动投喂 | 新买的彩票直接送入已解锁的刮票机，减少搬运 |
| 海绵、盘子价值与数量升级 | 提高手动劳动效率，让起步和补充资金更轻松 |

彩票、盘子和机器都能拖动。整理桌面、看机器运转、选择下一项升级，慢慢把最初的一块海绵变成一门猫粮生意。

自动投喂仍需要你购买彩票；桌上的机器负责干活，采购决策还得靠你。

### 两百万之后呢？

达到目标会出现通关结算，展示这一局的成果。你可以返回主菜单，也可以继续玩，看看这张小桌子还能赚多少。

<img src="Assets/Materials/Kitty2.png" alt="满意的猫老板" width="128">

*“Good luck! Meow!”*

## 上手很快，桌面很忙

- **猫咪带你入门**：NEW GAME 后出现五页引导，可前后翻页；洗盘按钮、Tickets 和 Gadgets 区域会随介绍高亮。继续存档不会重复播放。
- **看得到的成长**：设备升级、商店图标、彩票里程碑和顶部目标进度，让每一笔投入都有反馈。
- **像素风的小动静**：刮擦、金币、烟花、悬停弹性和机器运转效果，配上音效与背景音乐。
- **随时歇一会儿**：按 Esc 暂停，或保存进度后回主菜单。设置里可开启 Reduced Motion，减弱动效。
- **账算得明白**：金额保留完整数字与千分位；余额变长时字号会自动缩小，不会挤出商店。

## 怎么玩

| 操作 | 作用 |
| --- | --- |
| NEW GAME | 开始新的一局；已有进度时会要求确认覆盖 |
| CONTINUE | 继续保存的进度 |
| 点击 ONE MORE PLATE | 生成脏盘子 |
| 拖动海绵 | 擦洗盘子，赚取收入 |
| 点击 TICKETS / GADGETS | 切换彩票商店与设备商店 |
| 在彩票涂层上按住左键拖动 | 刮开彩票 |
| 按住彩票边框拖动 | 移动彩票，或送入自动刮票机 |
| 拖动盘子、机器 | 整理桌面位置 |
| 引导中的 NEXT / PREVIOUS | 前进 / 返回；最后点击 LET'S PLAY! 开始操作 |
| Esc | 游戏中暂停；暂停时恢复 |

**第一次玩的小建议：** 先洗盘子积累本金，体验几种彩票，再根据自己的节奏购买设备。别把全部现金都押在“再来一张”上——猫老板可以等，下一只盘子也可以。

## 在 Unity 中试玩

1. 克隆项目：

   ```bash
   git clone https://github.com/Grampusworld/Unity_Lottery.git
   ```

2. 在 **Unity Hub → Add project from disk** 中选择项目目录。
3. 使用 **Unity 6000.5.5f1** 打开，等待素材和软件包导入完成。首次导入需要网络访问软件包源。
4. 打开 `Assets/Scenes/SampleScene.unity`，点击编辑器的 **Play**。
5. 选择 **NEW GAME**，跟着猫咪完成引导，从第一只盘子开始。

场景、预制体和素材已包含在仓库中，正常试玩无需运行编辑器装配菜单。进度使用本机 `PlayerPrefs` 保存，不是云存档；NEW GAME 会覆盖已有游戏进度。

### 几个实现细节

- **刮开涂层**：运行时复制贴图并擦除像素，根据擦除比例结算，不改动源图片。
- **区分刮奖与拖票**：按下位置决定交互——涂层区域用于刮擦，边框用于拖动。
- **统一经济配置**：票价、解锁价、升级表、里程碑和通关目标集中在 `LotteryEconomy.cs`。README 不重复维护容易过时的完整价格表。
- **模态引导与菜单**：`MainMenuScreen` 统一控制暂停和输入阻挡；`NewGameTutorial` 管理页面、猫咪切换与目标高亮。
- **跨场景转场**：`ScreenFader` 使用不受暂停影响的时间推进淡入淡出，并在 New Game 重载期间保留遮罩。
- **完整金额显示**：`MoneyFormat` 统一处理货币格式，TMP 自动字号适配商店宽度；余额不足的抖动反馈也保留尺寸约束。

```text

  Editor/         场景装配与布局工具
  Fonts/          像素字体资源

  Materials/      猫咪、桌面、海绵和机器素材
  Prefabs/        彩票与盘子预制体
  Resources/      音效与背景音乐

  Scripts/        玩法、经济、交互、UI 与动效
Packages/         软件包依赖
ProjectSettings/  Unity 项目配置
```

想继续了解实现，可阅读 [新手引导](Docs/NewGameTutorial.md)、[主菜单](Docs/MainMenuScreen.md)、[彩票规则](Docs/NewTickets.md)和[经济系统与转场](Docs/EconomyV4AndTransitions.md)。专题文档中保留了一些历史设计与验证记录；当前行为和数值请以代码为准。当前经济校准工具是 `Tools/solve_economy.py`，`simulate_economy.py` 保留较早版本模型。
