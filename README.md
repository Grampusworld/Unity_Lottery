# Unity Lottery（挂个爽）

一款使用 Unity 6 和 C# 制作的 2D 像素风刮刮乐 + 放置小游戏。点击按钮领取彩票，用鼠标刮开涂层领取随机奖金；也可以手动刷盘子，或解锁自动洗碗机与自动刮彩票机，让余额自己涨。

> **项目状态：** 当前提供 Unity 工程，可在编辑器中试玩。仓库暂未提供可直接双击运行的游戏安装包或可执行文件。

## 玩法

### 刮彩票

1. 在左侧商店的 **TICKETS** 页点击票种按钮，花钱生成一张彩票。彩票会从屏幕右边界外飞入桌面，飞行途中带速度形变，**落地之前刮不动**。
2. 按住鼠标左键，在涂层上拖动刮开。刮开面积达到 80% 后自动揭晓奖金：结算瞬间会有一场**双层金白像素烟花**在票上绽放，然后更新右上角 **MONEY** 余额。
3. 彩票停留约 1.5 秒后消失（烟花先散完、票再消失），按钮恢复可用。没刮的票也可以**随时按住拿起**丢进自动刮票机（见下节）——机器没解锁时也能拿，只是松手后会飞回原位。

| 票种 | 售价 | 奖池（等概率） |
| --- | --- | --- |
| LUCKY | $10 | 0 / 5 / 10 / 20 / 50 |
| GOLD | $50（首次 $100 解锁） | 100 / 200 / 500 |
| NOVA | $50（首次 $1000 解锁） | 500 / 1000 / 2000 |

每种票累计刮满 10 / 25 / 50 张时，还会额外发放里程碑奖金。

### 自动刮彩票机

把彩票丢进去，机器自己刮、自己结算。

1. 在 **GADGETS** 页花 **$300** 解锁，机器会从上方落到桌面。
2. **按住左键 0.12 秒**把桌上的彩票拿起来（见下方「操作」），拖到机器上松手即投入。拖动途中指针一进机器范围，票会**自动缩小**提示「可以松手」；移开就恢复原尺寸。
3. 机内**串行处理**：同一时间只有队头那张在计时，它完成结算后下一张才从零起算；其余的票在槽位里静止排队。

机身下方有一块像素字**计数牌**，实时显示「机内票数 / 容量」（如 `2/5`），满仓时数字变金色提醒先取走已刮好的票。

| 升级项 | 效果 | 价格 |
| --- | --- | --- |
| SCRATCHER SPEED | 每级 −1 秒（8s → 3s），最高 5 级 | 每级 $1 |
| SCRATCHER CAPACITY | 每级 +1 张排队容量（1 → 6 张），最高 5 级 | 每级 $1 |

机身外观由**速度等级 + 容量等级**的总和决定，一共三档：

| 总等级 | 外观 |
| --- | --- |
| 0–3 | Retro CRT |
| 4–6 | Classic Blue |
| 7–10 | Gold Deluxe |

进度环只显示**队头**那张票的进度；升级换挡时机身外观、槽位布局与计数牌位置一起重排。

### 拖动桌面上的机器

自动洗碗机和自动刮彩票机都可以**按住左键直接拖动**，不需要长按：

- 松手后带**惯性滑行**，速度衰减到零后停下；撞到屏幕边缘会反弹。
- 机器之间、机器与桌面上的彩票互相**实体阻挡**，推不过去就沿边滑。
- 拖动范围被夹在桌面区域内，机器不会被拖出屏幕。

### 洗碗

- 点击 **One More Plate** 生成一个脏盘子，盘子会从屏幕右侧外**飞入**桌面上的随机空位，飞行途中带速度挤压形变、落地回弹；拖动海绵刷干净即可获得收入。
- **盘子也可以拖**：按住左键 0.12 秒拿起（和彩票同一套手势，带果冻与抬起放大），松手就留在原地，不会飞回去。
- 清洁分两档：
  - **初级海绵（黄）**：擦过的地方污渍**一层层变淡**，同一处约来回擦 3 笔才见底，要把整个盘子反复刷几遍。
  - **PURPLE SPONGE**（$30）：**一擦全净**——刷头碰到任何污渍，整盘污渍淡出后直接结算（刷头半径也翻倍）。
- 刷干净时屏幕上会飘出 **+$ 金额和一枚 3 帧复古金币动画**，金币飞向右上角余额后数字才滚动更新。
- **UNLOCK WASHER**（$200）：解锁自动洗碗机，每 10 秒自动产出 $5；可继续升级速度（最高 5 级）与容量（最高 5 级）。

商店里的购买/升级按钮有三种状态：可买（正常高亮）、**买不起/未解锁（灰显，点击会抖动余额提示）**、**已满级/已完成（金底金边的终态，不再响应悬停）**。

余额、解锁状态与升级等级保存在 `PlayerPrefs` 中，重开游戏会保留。

## 操作

| 按键 / 操作 | 作用 |
| --- | --- |
| 鼠标左键拖动 | 刮彩票、拖动海绵、**拖动两台机器**（松手带惯性） |
| 鼠标左键按住 0.12 秒 | 拿起桌面彩票或**脏盘子**拖拽；票拖进机器范围会缩小提示，松手投入，不在机器上则飞回原位（盘子松手留在原地） |
| 鼠标悬停 | 票、盘子、海绵、按钮、机器都会有果冻弹性反馈 |
| `F1` | 显示 / 隐藏 Debug 面板 |
| Debug 面板 `Reduce Motion` | 切换降低动效档（悬停果冻降到 80ms、无回弹、幅度减半） |

> 拿取与刮奖靠**是否移动**区分：按住后立刻拖动 = 刮奖，按住不动满 0.12 秒 = 拿起。

## 在 Unity 中试玩

1. 克隆仓库：

   ```bash
   git clone https://github.com/Grampusworld/Unity_Lottery.git
   ```

2. 在 **Unity Hub → Add project from disk** 中选择克隆得到的 `Unity_Lottery` 文件夹。
3. 使用 **Unity 6.5（6000.5.5f1）** 打开项目。首次打开时，Unity 需要导入素材和软件包，可能要等待一段时间。
4. 打开 `Assets/Scenes/SampleScene.unity`，点击编辑器上方的 **Play**。
5. 在 **Game** 窗口点击票种按钮，等彩票落到桌面后按住鼠标左键刮开。

场景与素材已经全部保存在仓库里，正常情况不需要额外操作。如果需要重建某个子系统，编辑器菜单 **Tools/挂个爽/** 下提供了幂等的一键装配工具，可重复执行：

| 菜单项 | 作用 |
| --- | --- |
| 一键挂载悬停果冻（Button + 海绵） | 总入口：给场景里所有 Button 和海绵补 `HoverJelly` |
| 给所有 Button 挂悬停果冻 / 给海绵挂悬停果冻 | 单独补某一类 |
| 一键装配洗盘机入场与进度环 | 重建洗碗机的盘子入场、水体与进度环 |
| 一键装配自动刮彩票机 | 导入机器素材、建物体树、铺 7 行 Gadgets 按钮、给票 Prefab 挂入场动画与拖拽 |
| 一键装配刮票机计数牌 | 重建机身下方的「机内票数 / 容量」像素计数牌 |
| 一键装配机器拖动 | 给两台机器挂拖动、惯性滑行与实体碰撞 |
| 给彩票挂入场动画与拖拽 | 给三个票 Prefab 挂 `TicketFlyIn` / `TicketDragger` 并回填引用 |
| 给彩票挂悬停果冻 | 给三个票 Prefab 根挂 `HoverJelly`（含 cover 层级守卫） |
| 给脏盘子挂飞入动画果冻与拖拽 | 重建盘子的飞入入场、果冻反馈与按住拖拽（旧名「…飞入动画与悬停果冻」保留转发） |
| 给余额文本挂金币抖动 | 重建余额不足时的红色抖动反馈 |
| 给票按钮加图标 | 按当前文案宽度重算三个出票按钮的图标位置 |

另外 `Tools/Lottery/Fix Shop Layout`（`ShopLayoutFix.cs`）是一个独立的、同样幂等的一次性修复工具：它把 `MONEY` 那行关掉自动换行并加宽，并把两个面板的行间隙统一成 22px、给每个按钮加 3px 描边。场景里已经应用过，正常不需要再跑。

## 实现要点

- **刮涂层**：运行时复制涂层贴图并擦除像素，不修改原始 PNG；按已擦除像素比例判定完成，同一张彩票不会重复结算。
- **奖池数据化**：奖池配置在各票种预制体的 `LotteryTicket.prizes` 上，新增票种只需加预制体 + 按钮 + 回填引用，不需要改脚本逻辑。
- **彩票入场动画**：`TicketFlyIn` 在初始化时把票挪到屏幕右边界外，再按 `easeOutCubic` 加抛物线弧度飞回桌位；形变由**当前速度**换算（越快拉得越长），落地再弹一下。全程关闭涂层输入与拖拽，只在落地回弹的最后一帧交还操作。
- **手势分流**：`TicketDragger` 用「按住静止 0.12 秒」区分拿取与刮奖 —— 位移超过容差即判定为刮奖并把输入交还给 `ScratchCard`，超时仍未移动才拿起（关闭涂层输入、抬升渲染层级、稍微放大）。拖动途中 `CanFeedAt`（与投料判定同源）每帧检测指针是否在机器可收范围上：在则把票平滑缩到 0.75 提示「可以松手」，离开则恢复抬起尺寸；投料失败会带着缩放平滑飞回原位。
- **自动刮彩票机**：`AutoScratcher` 给每张票一段独立状态机（入槽 → 计时 → 出槽），但**串行计时**——只有队头在累加时间，它结算后下一张才起算；等待的票静止排队，进度环只反映队头进度。容量因此是队列长度而非并行道数。槽位按机身贴图的**可见内容包围盒**现算并自动收敛列距/层距，票放在独立容器里（`localScale = 1`），不继承机身缩放。结算走 `LotteryGame.AwardMachineTicket`，与手动刮开共用同一套奖金与里程碑逻辑。
- **刮完烟花**：手动刮开揭晓的瞬间，`TicketFirework` 在票的位置运行时生成一张 `Texture2D` 炸开双层金白烟火（外圈金、中圈米白、少量红，粒子带重力下坠、末端闪烁熄灭），寿命 1.05s，比票的停留时间（1.5s）先结束；机器结算不叠烟花（已有爆点），Reduce Motion 档直接跳过。
- **运行时像素特效**：`ScratcherEffect` 和洗碗机的水体一样直接在运行时生成 `Texture2D`（横向刮擦头 + 落纸屑 + 每张票结算时一圈放射爆点），不引入粒子系统，也不需要额外美术资源；只在整数 texel 变化时重绘。
- **机器拖动三件套**：`MachineDrag` + `DragInertia` + `DragBodyRegistry` 共用「夹取 + 惯性 + 实体碰撞」——手写速度积分器，不挂 `Rigidbody2D`（机身入场、果冻、拖动本就在逐帧写 transform，再加物理体就是三个源抢同一个位置）。刮票机的 pivot 在可见内容底边、footprint 随等级变宽，抓取偏移与碰撞盒都按**当前档位的可见内容包围盒**现算；碰撞推回带 1e-4 容差，「刚好贴边」不算重叠，顶死时沿边滑而不是冻住。
- **计数牌走屏幕空间浮层**：像素字体的清晰度只由画布整数缩放决定，而整数缩放只对屏幕空间 Canvas 生效，所以机内票数/容量计数牌用主 Canvas 投影定位到机身上，而不是像进度环那样建世界空间 Canvas。
- **金币与抖动反馈**：`CoinGainFeedback` 在收入入账时飘出 3 帧金币动画并飞向余额，金币到位后余额才滚动到新值；`MoneyShake` 只由 `Spend()` 失败这一个事件触发，全场购买入口共用，纯呈现不碰存档。
- **进度环**：世界空间 Canvas + `Image`（Filled / Radial360）。直径按当前档位机身的**可见内容高度**决定，换档时重新居中 —— 直接用 `sprite.bounds` 会把透明留白也算进去，环会飘到机身外面。
- **像素字体**：使用 Press Start 2P，字体图集按 8px 采样点、`Padding = 5` 烘焙；`PixelPerfectCanvasScaler` 把画布缩放吸附为整数，字号取 8 的倍数，保证字形不发糊、笔画粗细一致。
- **悬停果冻反馈**：`HoverJelly` 组件用弹簧-阻尼积分驱动缩放（默认 22px 持续位移 / 30px 峰值，220ms 进入、160ms 移出），子级文字做反向缩放保持清晰，禁用状态与 reduced-motion 自动降级。彩票的果冻挂在票 Prefab 根上：封条（cover）是根的子物体，全票只有一个缩放写者，果冻放大时两层比例恒定、不会露出下层内容；飞行、拿起、进槽等会写彩票缩放的阶段各自独占、依次接管果冻开关。
- **2D 界面**：全部 UI 使用拉伸锚点 + 对称内缩，配合像素风彩票、桌面素材与字体。

```text
Assets/
  Editor/         编辑器批量装配工具（Tools/挂个爽/）
  Fonts/          像素字体资源
  Lotteries/      彩票底图、涂层和桌面素材
  Materials/      桌面、洗碗机、自动刮彩票机等素材

  Scenes/         游戏场景
  Scripts/        刮奖、彩票、洗碗、自动刮票机、结算与动效逻辑

```
