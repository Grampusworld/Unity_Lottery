# 挂个爽 · Lottery Mania

一款 Unity 6 + C# 的 2D 像素风**放置刮刮乐**。买彩票 → 鼠标刮开涂层领奖 → 钱升级自动洗盘机和自动刮票机 → 余额自己涨。

> **项目状态**：可直接在编辑器中试玩。仓库暂未提供可双击运行的安装包或可执行文件。

## 核心玩法

### 主菜单

启动显示 **NEW GAME / CONTINUE / SETTING**。NEW GAME 覆盖已有进度前需确认；无存档时 CONTINUE 置灰。游戏内按 `Esc` 打开暂停菜单，可恢复、设置或保存后返回主菜单。暂停时机器停止计时、桌面操作被拦住。详见 [主菜单说明](Docs/MainMenuScreen.md)。

### 刮彩票

1. 在左侧商店 **TICKETS** 页买票。彩票从屏幕右边界外飞入桌面（约 0.5 秒落地回弹），**落地前刮不动**。
2. 按住左键在涂层上拖动刮开。刮开 **85%** 自动揭晓奖金，结算瞬间在票上绽放**双层金白像素烟花**，随后更新 **MONEY** 余额。
3. 停留 0.35 秒后用 0.3 秒缩小退场。没刮完的票可以**随时拿起**丢进自动刮票机。

| 票种 | 售价 | 解锁价 | 奖池权重 | 空奖率 |
| --- | --- | --- | --- | --- |
| LUCKY | $13 | 初始开放 | 0 / 5 / 10 / 20 / 50 | 10% |
| GOLD | $31 | $83 | 0 / 0 / 25 / 25 / 50 / 50 / 75 / 100 | 15% |
| NOVA | $68 | $668 | 0 / 0 / 30 / 60 / 90 / 120 / 180 / 240 | 15% |
| HEARTMATCH | $134 | $2,461 | 0 / 0 / 0 / 200 / 200 / 200 / 600 | 32.86% |
| CROSSCODE | $300 | $9,070 | 0 / 0 / 250 / 250 / 500 / 750 / 1000 | 18.57% |
| ZIGZAG | $625 | $54,796 | 0 / 0 / 0 / 700 / 700 / 1400 / 2800 | 32.86% |

每种票累计刮满 **10 / 25 / 50** 张时额外发放里程碑奖金。票面另有特殊规则（连对、中心匹配、升序等），见 [新彩票说明](Docs/NewTickets.md)。

### 洗盘子

盘子是最初的资金来源，每只初始值 **$1**。

- **初级海绵（黄）**：污渍**一层层变淡**，同一处约 3 笔见底。
- **紫海绵**（$34）：**一擦全净** —— 刷头碰到污渍即整盘结算。
- 擦净时飘出 **+$ 金额**和 3 帧复古金币动画，金币飞向余额后数字才滚动更新。
- 盘子**也可以拖**：按下即拿起，可重叠堆放。

### 自动洗碗机（$103 解锁）

洗盘机自动把盘子洗成钱，速度与容量可升级。

- 洗盘机**可以拖动**：按住即拖，松手带惯性滑行，撞到边缘反弹，与机器/彩票实体阻挡。
- 机身有**进度环**显示当前轮次进度，世界空间 Canvas 跟随机身。

### 自动刮票机（$20,851 解锁）

把票丢进去，机器自己刮、自己结算。

1. 买票后**按住票的边框**拿起（按在涂层上是刮奖，按在边框外那圈才是拖拽），拖到机器上松手投入。拖动中指针进入机器范围时票会**自动缩小**提示可以松手。
2. 机内**串行处理**：同一时间只有队头那张在计时，其余静止排队。容量因此是队列长度而非并行道数。
3. 机身下方**计数牌**实时显示「机内票数 / 容量」，满仓时数字变金。

机身外观由**速度等级 + 容量等级**之和决定三档：0–3 Retro CRT、4–6 Classic Blue、≥7 Gold Deluxe。升级换挡时外观、槽位、计数牌一起重排。

### 自动投喂（$35,724）

买下的票跳过桌面直接进刮票机，消除纯体力的拖拽环节。仍需每 N 秒点一次买票 —— 刻意保留参与感。

## 数值与升级

全部数值集中在 **`Assets/Scripts/LotteryEconomy.cs`**，是唯一来源。改动前请先读该文件头的三条规则。

**通关目标：持有 $1,000,000。** 单局约 60 分钟。

| 升级项 | 效果 | 上限 | 价格 |
| --- | --- | --- | --- |
| PLATE VALUE | 每张盘子 $1 → $2 → $3 → $5 → $8 | 4 级 | $38 / 420 / 1,489 / 5,643 |
| MULTIPLE PLATES | 桌面同时可放 5 → 10 → 15 → 20 张盘 | 3 级 | 解锁 $29；升级 $889 / 3,194 / 12,071 |
| WASHER SPEED | 每轮 10s → 5s | 5 级 | $264 / 978 / 3,513 / 13,278 / 29,127 |
| WASHER CAPACITY | 每轮 5 → 7 → 9 → 12 → 15 张盘 | 4 级 | $309 / 1,154 / 4,210 / 16,188 |
| SCRATCHER SPEED | 每张 20s → 12s | 5 级 | $39,296 / 48,555 / 96,973 / 119,929 / 152,831 |
| SCRATCHER CAPACITY | 队列 1 → 6 张 | 5 级 | $44,141 / 88,158 / 109,026 / 138,938 / 173,420 |

一次性解锁：紫海绵 $34、洗碗机 $103、刮票机 $20,851、自动投喂 $35,724。

**三条设计规则**（改任何数字前先读）：

1. **价格 = 该级购买瞬间的收入速率 × 85 秒。** 回本时间恒定，成长节奏均匀。不要手改单个价格。
2. **全局倍率 `BoostPerLevel = 1.10` 是唯一的指数增长源。** 各链只负责功能与节奏，增长全由它承担。
3. **买下任意一级升级，所有收入乘一次倍率。** 37 级累计约 34 倍。

### 商店按钮三态

可买（正常高亮）/ **买不起（灰显，点击抖动余额）** / **已满级或已完成（金底金边终态，摘掉悬停果冻）**。

### GADGETS 行左侧图标

十个升级按钮左侧都有图标，且**随升级进度变化**：盘子图标旁叠加绿色上升箭头（每级多一段）、容量类图标里的盘子随等级增多、速度类用逐级点亮的箭头。满级时全部点亮并转为金色。

图标里的数量是**归一化**的：格子总数固定（= 满级 + 1），点亮数 = 等级 + 1。所以满级必然全亮，各行形态统一。图标复用既有美术素材，只有两支小箭头由编辑器脚本生成。

## 操作

| 按键 / 操作 | 作用 |
| --- | --- |
| 鼠标左键拖动 | 刮彩票、拖海绵、**拖盘子和两台机器**（松手带惯性） |
| 按住票的**边框** | 拿起彩票拖拽（按在涂层上是刮奖，两者靠位置区分而非计时） |
| 鼠标悬停 | 票、盘子、海绵、按钮、机器都有果冻弹性反馈 |
| `Esc` | 暂停 / 恢复；设置与确认框中返回 / 取消 |
| `F1` | 显示 / 隐藏 Debug 面板 |
| Debug 面板 `Reduce Motion` | 降低动效档（果冻 80ms、无回弹、幅度减半） |

余额、解锁状态与升级等级存在 `PlayerPrefs`，重开保留。

## 在 Unity 中试玩

1. 克隆仓库：

   ```bash
   git clone https://github.com/Grampusworld/Unity_Lottery.git
   ```

2. Unity Hub → **Add project from disk**，选择克隆得到的目录。
3. 使用 **Unity 6.5（6000.5.5f1）** 打开。首次导入素材与软件包需等待。

## 实现要点

- **像素完美**：Press Start 2P 按 8px 采样烘焙、字距取整；`PixelPerfectCanvasScaler` 把画布缩放吸附为**整数**倍。非整数缩放会让像素字发糊，这是全项目的硬约束。字号只取 8 的倍数。
- **列表滚动不用 `ScrollRect`**：它的 `anchoredPosition` 是连续浮点，滚一半字体就糊。`PixelRowScroll` 只写整数、整行步进，是唯一能保住像素网格的滚法。
- **刮涂层**：运行时复制涂层贴图并擦除像素，**不修改原始 PNG**；按已擦除比例判定完成，同一张票不会重复结算。
- **手势分流按位置而非计时**：按在涂层实体上 = 刮奖，按在涂层外那圈边框 = 立刻拿起。涂层范围由 `ScratchCard.CoversPoint` 自量，不在别处手抄尺寸。
- **拖拽不用 `Rigidbody2D`**：机身入场、果冻、拖动本就在逐帧写 transform，再加物理体就是三个源抢同一个位置。改用手写速度积分器 + 最小穿透轴推回 + 沿边滑。
- **「贴边」必须留容差**：推回量就是精确 overlap，落点必然精确贴边，判据写 `>= sum − 1e-4`。用严格 `>` 会让每次成功推回都被自己否掉，机器顶到东西上会直接冻住。
- **抓取让路集中在 `DragBodyRegistry.Claimant(world)` 一处**，优先级 **海绵 > 票 > 机器 > 盘子**。票压过机器是刻意例外（票画在机器下面，不让就会被压死抓不回来）。
- **退场统一走 `ShrinkOut`**：0.3 秒线性缩到 5% 再销毁，替代一帧 `Destroy`。入场、拿起、进槽等会写 `localScale` 的阶段各自独占、依次接管。
- **果冻只反向缩放文字**：`HoverJelly` 挂在票 Prefab **根**上（cover 是子物体），全票只有一个缩放写者，两层比例恒定、不会露出下层。
- **静态表会被域重载清空**：`DragBodyRegistry` 是 `static`，Play 中改脚本触发重编译会整张丢失且不抛异常，只表现为「按下去没反应」。所以每帧做 presence 自检补登记；实例级追踪表字段一律 `[SerializeField]`，并在 `OnEnable` 收编孤儿。
- **计数器走屏幕空间浮层**：像素字清晰度只由画布整数缩放决定，而整数缩放只对屏幕空间 Canvas 生效，所以计数牌用主 Canvas 投影定位，不建世界空间 Canvas。
- **运行时生成特效**：烟花、洗碗机水体、刮擦头、进度环贴图都在运行时用 `Texture2D` 画，不引入粒子系统也不需额外美术资源，且只在整数 texel 变化时重绘。
- **计数器与游戏速度平衡**：通关节奏由 `LotteryEconomy` 顶层的校准模拟保证，改数值后需重跑校准而非肉眼估。

## 项目结构

```text
Assets/
  Editor/         幂等装配工具（Tools/挂个爽/ 与 Tools/Lottery/）
  Fonts/          Press Start 2P 字体资源
  Lotteries/      六种彩票的底图与涂层
  Materials/      桌面、洗碗机、刮票机、刷子、进度环
  Prefabs/        彩票与脏盘子预制体
  Resources/      音效与 BGM（Resources.Load 加载）
  Scenes/         SampleScene.unity（唯一场景）
  Scripts/        玩法与动效逻辑
Packages/         Unity 软件包清单
ProjectSettings/  项目设置
Docs/             专题说明文档
```

| 脚本 | 职责 |
| --- | --- |

| `GadgetRowIcon.cs` | GADGETS 行左侧图标的进度驱动 |
| `AutoScratcher.cs` / `ScratcherEffect.cs` / `ScratcherCountLabel.cs` | 刮票机状态机、运行时特效、机内计数牌 |
